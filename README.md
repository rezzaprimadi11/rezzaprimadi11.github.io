# GAMI Corporation — Website

Situs statis bilingual GAMI Corporation Indonesia. File dalam arsip ini siap di-host di GitHub Pages.

## Cara memasang

1. Ekstrak file ZIP ini di komputer. Jangan unggah file ZIP sebagai arsip—unggah **isi** hasil ekstraknya.
2. Buat repository GitHub, lalu unggah `index.html`, folder `assets/`, `images/`, dan file lain dari hasil ekstrak ke **root** repository.
3. Buka **Settings → Pages** di repository.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu simpan.
5. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat situs di halaman Pages.

Semua alamat aset menggunakan path relatif, sehingga situs ini dapat dibuka di GitHub Pages tanpa perlu mengganti nama repository atau menjalankan proses build.
